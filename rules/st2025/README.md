# Reglas ST 2025 ↔ FINREP/COREP

Vacío a propósito. Aquí van los YAML que salen del flujo de extracción
(`cuadre-extract export`) una vez revisados por una persona.

- `normativa.yaml`: cuadres citados literalmente en la guía/metodología EBA.
- `plantilla.yaml`: controles internos de las propias plantillas ST.
- `propuestas.yaml`: cuadres sugeridos, no normativos (`gravedad_maxima: Leve` mientras no se revisen).
